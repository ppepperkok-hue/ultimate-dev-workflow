# 确立核心价值（Core Value）

## 目的

回答「凭什么做这个项目」：为谁、解决什么、为什么现在值得做。

## 输入

- 用户的一句话需求或模糊想法

## 执行方式

1. 识别核心用户与核心场景（2-3 个）。
2. 提炼痛点与机会：现状是什么、差在哪、不做会怎样。
3. 写一句话价值主张：为 [谁] 解决 [什么问题]，带来 [什么结果]。
4. 区分核心价值与附加价值：砍掉非核心，避免价值堆砌。

## 产出

- 一句话价值主张
- 核心用户与核心场景清单
- 价值边界：明确不解决什么

## 验收门

- 一句话能讲清，外行听得懂
- 核心场景能举出具体例子
- 价值边界明确，无「顺便也做」

通过后进入「明确项目核心目标」。
