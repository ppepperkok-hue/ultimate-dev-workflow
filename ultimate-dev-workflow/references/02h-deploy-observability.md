# 部署、可观测性与安全（Deploy & Observability）

## 本步定位

选型第 8 层：决定东西跑在哪、怎么知道它坏了、怎么防出事。

## 决策内容

- 部署目标：VPS / 容器 / Serverless / PaaS / 桌面分发
- 发布流程：构建、镜像、迁移、回滚
- 可观测性：结构化日志、健康检查、指标、告警
- 认证授权与密钥管理：Auth 方案、密钥注入、环境变量
- 备份恢复与合规要求

## 评估维度

- 项目规模与预算
- 团队运维能力
- 数据敏感度与合规约束

## 原则

- 部署形态由项目类型与预算决定，不默认上 K8s。
- 可观测性最小方案先行：结构化日志 + 健康检查 + 告警。
- 密钥永远不进代码库与 lock file。

## 验收门

- 部署路径明确，发布/回滚可执行
- 监控与告警有方案
- 密钥与敏感信息处理安全
- 用户确认

通过后选技术栈完成，进入项目架构。
