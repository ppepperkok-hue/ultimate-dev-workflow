# 自动续入上下文（Context Injection）

## 本步定位

利用 agent 的自动加载机制，让指定位置的规则在会话开始时自动进入上下文，不靠手动提醒。

## 执行方式

1. 确认 agent 的自动加载机制：Codex 会自动读取工作目录及上级目录的 `AGENTS.md`，以及全局 `AGENTS.md`。
2. 验证路径：在项目根放置 `AGENTS.md`，确认新会话开始时可见。
3. 入口文件（`AGENTS.md`）保持精炼；详细规则用相对路径引用，需要时再读。
4. 划分常驻内容与按需内容：强制项（验证纪律、权限、冲突规则）必须常驻；详细技术规则按需加载。

## 验收门

- 自动加载路径实测确认（新会话能看到）
- 常驻内容与按需内容划分明确
- 引用路径正确，agent 能按路径读到

通过后进入「任务前全量加载」。
