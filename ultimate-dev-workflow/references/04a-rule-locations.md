# 指定规则位置（Rule Locations）

## 本步定位

决定「规则住在哪」：位置固定、分层清晰、无散落副本。

## 位置分层（骨架）

1. **项目根 `AGENTS.md`**：项目级宪法，必须存在。
2. **全局 `AGENTS.md`（`~/.codex/AGENTS.md`）**：个人与通用规则。
3. **`docs/architecture/rules.md`**：详细技术规则（03b 产出），由 `AGENTS.md` 引用。
4. **子目录 `AGENTS.md`**：仅当子域规则量大时使用，且必须被根 `AGENTS.md` 索引。

## 规则

- 一条规则只存在于一个指定位置，不复制到多处。
- 详细规则放引用文件，入口只放索引与强制项。
- 新规则先找位置，找不到就建位置，不许随手写进对话。

## 验收门

- 位置清单明确，无散落规则
- 每份规则文件有唯一所有者（入口或引用文件）
- 用户确认
