# 前端技术栈（Frontend）

## 本步定位

选型第 1 层：决定用户界面用什么技术呈现。

## 决策内容

- 前端框架：React / Vue / Svelte / 原生 / SSR 框架（按项目类型：Web、移动、桌面、游戏）
- 语言与方言：TypeScript / JavaScript
- 状态管理：是否需要，选型
- 样式方案：CSS 方案、预处理器、原子化样式
- 构建与打包：Vite / webpack / 框架内置构建

## 评估维度

- 项目类型与交付形态（SPA / SSR / 静态站 / 桌面壳 / 移动端）
- 团队熟悉度、生态成熟度、长期维护成本
- 性能与包体预算
- 与目标部署环境的兼容性

## 原则

- 类型安全优先，默认 TypeScript。
- 框架选择看生态与学习成本，不追新。
- 产出记录：框架、语言、状态管理、样式方案、构建工具及各自理由。

## 验收门

- 每项选择有 ADR，否决项有记录
- 与立项清单的项目类型匹配
- 用户确认

通过后进入「UI 组件库」。
