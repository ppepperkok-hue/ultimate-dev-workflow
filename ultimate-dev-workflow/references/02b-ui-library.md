# UI 组件库（UI Library）

## 本步定位

选型第 2 层：决定界面组件与视觉基础。

## 决策内容

- 组件库：shadcn/ui、Ant Design、Element Plus、MUI、Radix、Tailwind 生态等
- 设计系统与主题：品牌 token、暗色模式
- 图标与字体方案
- 重型组件是否引入：图表、富文本、表格虚拟滚动

## 评估维度

- 与前端框架的绑定兼容性（先确认 02a）
- 可定制性：主题 token 能否覆盖品牌
- 包体与性能成本
- 许可证与维护状态

## 原则

- 可定制性优先于现成炫酷：组件库是基础，不是终点。
- 组件库不解决业务组件；业务组件自行沉淀。
- 不重复造轮子，也不为少写代码引入笨重库。

## AI 适配检查

- 选文档完整、示例多的组件库，AI 可查官方文档
- 源码可见/可定制的库（如 shadcn 风格）更利于 AI 修改
- 组件用法有官方示例，避免 AI 靠猜测拼 API

## 验收门

- 与前端框架兼容
- 可主题化、许可清晰、包体可接受
- 用户确认

通过后进入「后端语言」。
