# 强制读取验证（Enforce Read）

## 本步定位

保证「指定位置必须被读取到」真实发生：有检查，不靠自觉。

## 执行方式

1. **完整性校验**：脚本检查指定位置文件存在、非空、引用路径有效。
2. **内容校验**：`AGENTS.md` 的强制项（验证纪律、权限、冲突规则）关键字存在。
3. **会话内强制**：任务开始第一动作必须读取（配合 04c）；agent 汇报时声明遵循的条款。
4. **CI/预检**：把校验脚本挂进 CI 或项目初始化流程。
5. **违规处理**：发现未加载就开工，停下补读再继续。

## 产出

- 校验脚本（可执行）
- 强制项清单

## 验收门

- 校验脚本实测可跑，能抓出缺失
- 强制项清单与 `AGENTS.md` 一致
- 用户确认

通过后 Agent 宪法完成，进入 Phase 1 开发（待补）。
