# 搭建最小骨架（Minimal Skeleton）

## 本步定位

把最小架构范围落成可运行骨架：目录立起来，最小链路真实跑通，验证命令全部可执行。

## 执行方式

1. 按 03b 规则落目录骨架。
2. 搭建最小横切链路：配置加载、日志、健康检查、错误处理、数据库连接。
3. 打通端到端最小链路：请求 → 业务 → 存储 → 响应。
4. 验证命令全部可跑：lint、类型检查、测试、启动、构建。
5. 写 `docs/architecture/skeleton.md`：结构说明、启动方式、验证命令。

## 验收门

- 最小链路真实跑通（不是只建了目录）
- 验证命令在干净环境可复现
- 骨架内无「本期不做」清单外的功能
- 用户确认

通过后进入「建立功能接入规则」。
