# 明确项目核心目标（Core Goals）

## 目的

把价值转成可测量、可验收的目标，定义「做成什么样算成功」。

## 输入

- 已确认的核心价值文档（价值主张、用户与场景）

## 执行方式

1. 由价值主张导出 2-5 个核心目标。
2. 每个目标配成功标准：可测量、可验收、有时间或质量约束。
3. 目标排序：必须达成 / 应该达成 / 可以达成。
4. 每个目标绑定验收方式（测试、演示、指标、用户反馈）。

## 产出

- 核心目标清单（含优先级）
- 每个目标的成功标准与验收方式

## 验收门

- 目标全部可测量，无「尽力做好」类表述
- 优先级明确，资源冲突时有取舍依据
- 成功标准与用户预期一致，用户确认

通过后进入「功能细化拆解」。
