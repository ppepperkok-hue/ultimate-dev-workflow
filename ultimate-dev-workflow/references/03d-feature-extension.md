# 建立功能接入规则（Feature Extension）

## 本步定位

定义「以后每个功能怎么加」：统一开发规则的落地机制，确保新增功能走同一条路。

## 执行方式

1. 定义功能接入流程：取 backlog 单元 → 查规则 → 在骨架内增量实现 → 过验证门。
2. 建功能模块模板：目录结构、入口注册、接口实现、测试样板，复制即用。
3. 明确禁止项：新功能自带新架构、绕过规则、复制粘贴改命名。
4. 定每功能交付检查单：规则符合、测试通过、文档更新、无残留。
5. 用模板实测生成一个示例功能，验证流程可走通。

## 产出

- 功能接入流程文档
- 功能模块模板（模板代码 + 测试样板）
- 每功能交付检查单

## 验收门

- 模板实测可生成一个可运行、过验证的功能
- 检查单可执行，不依赖记忆
- 用户确认

通过后项目架构完成，进入 Agent 宪法。
