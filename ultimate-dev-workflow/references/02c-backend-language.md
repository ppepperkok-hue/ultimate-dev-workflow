# 后端语言（Backend Language）

## 本步定位

选型第 3 层：决定服务端逻辑用什么语言与运行时。

## 决策内容

- 语言与运行时：Python / Node / Go / Rust / Java / C# 等
- 运行时版本与生态
- 并发模型与性能预期
- 部署形态约束（Serverless 冷启动、容器镜像大小）

## 评估维度

- 项目类型：API 服务、数据管道、多 Agent 系统、CLI 工具
- 生态成熟度：库、框架、社区
- 团队熟悉度与可维护性
- 性能、内存、启动时间需求

## 原则

- 按任务形态选，不按喜好选：数据管道 ≠ Web 框架 ≠ 桌面 CLI。
- 与既有系统语言栈一致优先。
- 否决项要记：例如「为了快选 Rust，但团队无人会写」= 否决。

## 验收门

- 语言能支撑立项清单的性能与生态需求
- 许可清晰、运行时可部署
- 用户确认

通过后进入「开发框架」。
