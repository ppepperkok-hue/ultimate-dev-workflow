## 实现契约

1. 接口实现：入参/出参/错误约定引用 02f 契约，不另造。
2. 数据结构：引用 02e schema；新增表/字段走迁移文件并记录。
3. 配置：新增配置项进环境变量与 `.env.example`，不硬编码。
4. 日志：按项目日志规范落点，失败显式留痕。
5. 测试：单元测试 + 真实输入冒烟；修 bug 先写失败测试。

## 完成检查单（每功能交付前过一遍）

- [ ] 规则符合（03b）且无越界实现
- [ ] 接口与数据结构引用既有契约，无新造轮子
- [ ] 验收命令全绿（测试/lint/类型/真实输入）
- [ ] 文档同步（实施真元文档、README、rules）
- [ ] 无残留（死代码、临时代码、调试输出）

## 实测要求
