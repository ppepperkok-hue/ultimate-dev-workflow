# 跨领域坑库

从真实项目（AI 流水线、多 Agent 系统、桌面应用、前端面板）实战中提炼。每条：现象 → 根因 → 规避。

## 1. 环境与编排

### 1.1 运行时默认禁用能力

现象：功能/节点配置正确却不可用（例如编排器默认禁用本地命令节点）。

根因：运行时默认排除高风险能力，配置没跟上。

规避：启动脚本统一注入所需能力与环境变量（如 `NODES_EXCLUDE=[]`）；文档写明唯一启动入口，禁止绕过。

### 1.2 版本不兼容导入失败

现象：从旧版本导出的产物导不进新版本（如 `propertyValues[itemName] is not iterable`）。

规避：以仓库内源文件为唯一真相，不用旧版导出/旧标签页编辑覆盖；升级前先验证兼容。

## 2. 生成物与模板

### 2.1 模板语法假绿灯

现象：校验显示正常，一跑就挂在第一个节点；批量注入后 10+ 处引号/闭合错误。

根因：手工拼接模板/表达式，中文与引号混排，且没有语法校验。

规避：业务参数资产化（独立文件 + frontmatter），生成器产出最终产物；校验脚本对每个表达式做语法检查；禁止手改生成物。

### 2.2 模板字符串转义

现象：用 `.format()` 生成代码时，模板里的花括号被当作占位符（KeyError）。

规避：模板插值用唯一占位符替换（如 `__PKG__`）或全部转义；生成后实测运行再交付。

## 3. 进程与数据传递

### 3.1 命令行长度上限

现象：大 JSON 在脚本间丢失或命令失败（Windows cmd 上限 8191 字符）。

规避：大 payload 写临时文件，脚本用 `--file` 读取；参数只放路径与少量标量。

### 3.2 路径硬编码 / 双解释器

现象：换机器/换盘全部失效；命令里解释器出现两次（让解释器解析解释器）。

规避：解释器、项目根、密钥全走 env；校验脚本断言参数首元素不是解释器；脚本自身相对定位。

### 3.3 子进程中文乱码

现象：子进程输出抛 UnicodeDecodeError 或中文变 `?`。

规避：统一 UTF-8；子进程读取用 `errors="replace"`；跨进程中文数据走文件或标准库 HTTP；终端脚本开头 reconfigure UTF-8。

## 4. LLM/外部服务调用

### 4.1 空响应当成功

现象：任务 0.5 秒结束、无报错、无结果。

根因：空 content/空结果被当作成功继续。

规避：空结果显式报错并重试；失败写日志/留痕。

### 4.2 输出截断但检查通过

现象：长输出被容量参数截断，检查只看已有内容仍放行。

规避：显式容量上限（按任务动态）；完整性校验（长度/结束标记/结构化字段齐全）。

### 4.3 JSON 解析脆弱

现象：下游直接 parse 外部输出，非 JSON 时整条链中断。

规避：解析失败返回软失败并留痕；构造失败场景测试。

### 4.4 强制参数被拒

现象：某些模式不接受强制参数（如强制 tool_choice 报 400）。

规避：先查模型/服务行为；能自动就自动，异常降级路径必须有。

### 4.5 没抓真实请求就实现

现象：外部 API 报错摸不着头脑，或签名/限额不符。

规避：先抓真实请求（请求体、头、签名、错误码），记录到文档再写代码；错误码映射表先行。

## 5. 并发与后台任务

### 5.1 双发

现象：定时 + 手动同时触发，同一操作执行两次。

规避：原子创建锁（O_EXCL）；触发前检查幂等标志；所有入口共用同一把锁。

### 5.2 残留锁 / PID 复用

现象：异常退出后锁永久占用；PID 被复用导致误判。

规避：锁文件记录 PID + 时间戳；陈旧回收阈值大于单次运行时长；所有退出路径（成功/失败/异常）释放；提供手动释放工具。

### 5.3 后台任务僵尸

现象：重启后任务永久占位；用户取消无效；关闭界面后台继续烧资源。

规避：心跳机制（创建写初始心跳，超时自动标 failed）；取消在写入下一状态前校验状态；状态机明确；轮次/超时上限；界面关闭不等于任务停止，必须显式取消。

### 5.4 全局锁死锁

现象：长任务持有全局锁，其他任务全部阻塞。

规避：锁粒度按任务/资源拆分；只锁临界区。

## 6. 数据层

### 6.1 空载荷垃圾数据

现象：无输入时写入默认/空对象，污染数据。

规避：空载荷直接跳过；入口预检（无目标直接 blocked）。

### 6.2 迁移孤儿

现象：删主行后子表留孤儿引用，查询崩溃或数据错乱。

规避：删除前清理全部子表；保留有价值行优先；兼容旧数据库的 SQL 写法；迁移有测试。

### 6.3 非幂等写入

现象：同一执行多次触发重复记账/重复行。

规避：唯一约束 + 幂等键（执行 ID）；upsert 语义；成本/日志按幂等键去重。

### 6.4 上下文 ID 不穿透

现象：多实例/多业务数据串扰（A 的数据出现在 B）。

规避：业务 ID 从入口穿透到每个调用（函数参数/请求体/脚本参数），存储层按 ID 过滤；校验脚本断言关键调用都带 ID。

## 7. 界面与实时通道

### 7.1 假数据死模块

现象：界面区块永远为空或显示占位，后端没有对应字段。

规避：审查时逐字段对照后端；无数据源的区块删除或接真实数据；每个按钮追到真实 handler。

### 7.2 实时通道覆盖轮询

现象：推送快照把完整列表截断（永远只显示最新几条）；断连后卡在旧状态。

规避：快照只补头部/合并，页面以完整轮询为准；SSE 断连自动重连 + 轮询兜底。

### 7.3 时区错位

现象：「今日」统计在凌晨全错。

规避：前端「今日/本周」用本地日期，禁止 `toISOString()`（UTC）与本地时间字符串混用。

### 7.4 硬编码数字

现象：版本号、节点数、上限写死且互相矛盾。

规避：从后端/配置动态取；前后端上限一致并加回归测试。

## 8. 桌面与交付

### 8.1 壳不稳定

现象：无边框窗口拖动失效、偶发退出、白屏闪烁。

规避：需要「真软件窗口」体验时选成熟壳（如 Electron：托盘/通知/自启/自动更新）；放弃不稳定方案及时切换；窗口 `ready-to-show` 后再显示，页面内联背景色防白闪。

### 8.2 附属进程生命周期

现象：主程序退出后附属服务残留，或重启后端口占用。

规避：启动前探测端口，未占用才拉起；退出时回收自起进程；单实例锁。

## 9. 编码与环境差异

### 9.1 编码不一致

现象：Windows 中文乱码、GBK 读 UTF-8 崩、管道编码异常。

规避：全链路 UTF-8；工具脚本读文件显式 encoding；校验工具本身也要显式 UTF-8（工具自身也会踩）。

### 9.2 换环境失效

现象：换机器/换盘后所有路径失效。

规避：env 参数化 + 相对定位 + 校验脚本断言。

## 10. 测试与审查

### 10.1 测试污染真实环境

现象：测试触发真实外部调用、写真实库。

规避：临时目录/临时库；外部调用 mock；测试入口隔离运行时产物。

### 10.2 审查没有证据

现象：「再审查一遍」没有记录，修了又漏。

规避：标准审查流程：证据优先、字段对照、动作对照、P0–P3 分级、报告归档、附验证命令。

### 10.3 只测单元不测端到端

现象：单元全绿，真实链路一跑就断。

规避：每阶段至少一次端到端实跑；关键链路有集成测试。

### 10.4 文档失真

现象：README 声称已实现/已跑通，实际没有。

规避：文档数字与代码对照；「待办」与「已做」分开；每次改动同步文档。
