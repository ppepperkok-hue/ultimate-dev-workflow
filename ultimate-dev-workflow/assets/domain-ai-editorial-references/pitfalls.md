## 1. 编排层（n8n）

### 1.1 工作流导不进 / executeCommand 禁用

现象：导入工作流报 `propertyValues[itemName] is not iterable`；或工作流里 executeCommand 节点不可用。

根因：n8n 2.x 默认禁用本地命令类节点，必须显式 `NODES_EXCLUDE=[]`；不同 n8n 版本导出的 JSON 不兼容。

修复：用启动脚本注入环境变量再拉起 n8n；工作流始终以仓库内源 JSON 为准，不用浏览器旧标签页编辑（旧版本会覆盖服务器新版本）。

预防：启动脚本固定为唯一入口（注入 `NODES_EXCLUDE=[]`、`NODE_FUNCTION_ALLOW_BUILTIN=fs` 与全部业务 env）；文档写明「不要用浏览器旧标签编辑工作流」。

### 1.2 表达式语法错误假绿灯

现象：工作流校验显示正常，一跑就挂在某个 LLM 节点；手动注入 bible 后 15 个节点里 10 个 JS 语法错误（多引号、缺闭合引号、多余 `+'`）。

根因：直接在 JSON 里手拼 `jsonBody` 表达式，中文与引号混排极易出错，且没有校验工具。

修复：编写渲染脚本（`render_workflow.py`）从 Agent 提示词资产生成节点；校验脚本对每个 jsonBody 表达式做语法检查（`check_expr.js` 或等价实现），任何节点语法错误立即失败。

预防：禁止手改工作流里的 LLM 节点表达式；所有提示词/任务模板走资产文件；validator 增加表达式语法断言。

### 1.3 大 payload 在脚本间丢失

现象：周会蓝图、日更结果等大 JSON 传不到 Python 脚本，或命令执行失败。

根因：Windows cmd.exe 命令行上限 8191 字符。

修复：code 节点把大对象写 `n8n_tmp/*.json`，Python 端用 `--file` 读取。

预防：任何可能超过 1KB 的数据一律文件传递；脚本参数只放路径与少量标量。

### 1.4 失败被静默吞掉

现象：某轨 LLM 失败后工作流「看起来成功」，章节无痕消失；或 `continueRegularOutput` 导致下游不执行、无日志。

根因：错误处理策略错误——容错把可见报错变成了无痕断链。

修复：16 个关键节点全部 `continueErrorOutput`，error 分支接到「失败留痕」节点，汇总运行结果消费 `llm_fail` 为未落库的轨补写 draft+error；合并节点用唯一端口接收复核/兜底/留痕四路输入。

预防：失败路径必须显式落库；validator 断言 error 边、merge 端口唯一且连续、汇总对未覆盖轨一律补录。

### 1.5 分支引用未执行节点

现象：存稿充足分支跑「全员写日记」时引用「解析本地资料」（只在现造分支执行），直接失败。

根因：节点引用没有考虑分支可达性。

修复：改引用两条分支都会执行的「读当前书」。

预防：任何跨分支引用必须检查上游可达性；validator 做节点级 BFS 可达性检查。

### 1.6 重复边导致多倍执行

现象：周会某节点出现三条相同连线，一次触发跑三次，烧三倍会议成本。

根因：多轮修补时重复加边。

修复：去重；validator 增加全工作流重复边检查。

## 2. 发布层（番茄平台）

### 2.1 发布失败常见报错

现象：章节发布失败，报 `-3007`（标题长度/格式）、`-2`（章节字数不足）、`-3026`（大段重复）、`-1019`（每日提交字数超限）。

根因：平台硬规则与本地假设不一致（标题没带「第 N 章」、正文不足 1000 字、同文案连发、日更批次过大）。

修复：标题生成强制「第 N 章 标题」格式；质量门校验字数下限；单日两章约 4400 字安全；发布失败保留 `reviewed` 状态次日可补发。

预防：把平台规则写进文档并前置校验；发布前预检 Cookie、预算、作品绑定、字数。

### 2.2 建书被风控拒绝

现象：直接 HTTP 调建书接口返回「参数有误」或风控错误。

根因：番茄作者 API 部分接口要求 `msToken` / `a_bogus` 签名，纯 Cookie + CSRF 不够。

修复：当前方案走浏览器登录态操作（bb-browser 注入 Cookie 后页面建书），自动建书接口签名适配登记待办；抓真实请求逆向签名后补齐。

预防：平台自动化前先抓真实请求确认签名要求；失败信息如实展示，不假成功。

### 2.3 Cookie 过期与账号状态

现象：一段时间后发布全部失败；或建书后当日额度用尽无法重试。

根因：Cookie 约 1–2 个月失效；番茄每天限建 1 本。

修复：预检检查 Cookie 存在性；文档提示定期抓取；建书失败次日重试。

### 2.4 多书发布错书

现象：绑定新书后 n8n 进程还读旧环境变量，发到旧书。

根因：n8n 进程不重读 `.env`；硬编码 `FANQIE_BOOK_ID`。

修复：新增「读当前书」节点从数据库读 book_id（fallback env），绑定新书后无需重启 n8n。

预防：按书状态机（planning/ready/publishing）管理，发布链路统一从数据库取当前书。

## 3. LLM 与 Agent

### 3.1 空 content 被当作成功

现象：日更 0.6 秒结束、无报错、没发出去。

根因：LLM 返回空字符串被当作成功，链路继续。

修复：空 content 返回失败并留痕可重试；代理接口对空响应显式报错。

### 3.2 max_tokens 截断正文

现象：2000+ 字正文被截断，但质量门只数已有字数仍放行发布。

根因：正文类节点没配 max_tokens，走 1600 兜底。

修复：正文 Agent 显式 `max_tokens`（写手/润色按字数动态，4000+）；结构化审阅类 2000–3000；validator 断言关键节点 max_tokens。

预防：所有 LLM 节点在资产 frontmatter 里显式声明 max_tokens，禁止依赖兜底。

### 3.3 JSON 解析脆弱

现象：审稿/读者/主编输出非 JSON 时下游 throw，整轮中断。

根因：质量门直接 `JSON.parse` 无容错。

修复：解析失败返回 `passed:false` 软失败并落库留痕；复核接口返回非 JSON 时输出 unknown 容错。

### 3.4 强制 tool_choice 失败

现象：DeepSeek V4 thinking 模式传 `tool_choice` 报 400。

修复：一律不传 tool_choice；首轮带工具声明，模型自主发 `tool_calls`，本地检索后以 `role:"tool"` 回传，二轮输出；工具调用异常降级无工具单轮。

预防：工具循环做成标准库函数（agent_tool_loop），不散落各节点。

### 3.5 工具调用级观测缺失

现象：只知道 Agent 最终输出了什么，不知道它检索过什么知识。

修复：每次工具检索独立落一条活动日志（knowledge_lookup：检索词、命中文件/条数），任务完成日志里带 `used_knowledge` 汇总。

## 4. 多 Agent 会议

### 4.1 全局锁死锁

现象：会议线程持全局锁直到整场结束，等待用户输入的会议永久堵死后续会议。

修复：`create_session` 检查已有 active 会议并友好拒绝；会话线程内使用专用锁而非全局长锁。

### 4.2 僵尸会话

现象：web_api 重启后 running 会议永久占位，新会开不了。

修复：心跳机制——`create_session` 写初始心跳；`get_active_session` 对心跳超过 10 分钟的 running 会话自动标 failed；`awaiting_input` 是合法停车状态不误杀。

### 4.3 取消被覆盖

现象：用户取消会议后，线程每轮结束无条件写 `awaiting_input`，把 cancelled 复活。

修复：写入前校验 `status != 'cancelled'`；取消按钮真正终止后台线程并提示「关闭面板不会停止后台会议」。

### 4.4 发言乱码

现象：会议直播显示 `?????:?????`。

根因：PowerShell 5.1 `Invoke-RestMethod -Body <string>` 发中文变 `?`。

修复：带中文的 API 调用改用 Python urllib + UTF-8 body；面板内浏览器调用不受影响。

### 4.5 发言 JSON 截断

现象：发言栏报 `Expected ',' or ']' after array element in JSON at position ...`；有人不说话。

修复：发言固定六段结构（本周小结/感受/意见/顾虑/提案/优先级）；缺段重试一次；全部重试失败保留 raw 原文展示；单 Agent 失败不影响他人。

### 4.6 历史只带最近两条

现象：讨论没有延续性，后面几轮忘掉前面内容。

修复：记忆官增量压缩——每轮把新发言合并进 running summary（`compress_history`），上下文 = 压缩摘要 + 本轮材料，不丢历史也不撑爆窗口。

### 4.7 轮次锁死不健壮

现象：固定三轮无法适配讨论节奏。

修复：专题会议每轮结束停在「等待输入」，用户可插话指示或手动「结束并总结」；定时周会保留固定轮数 + 主席总结。

### 4.8 无书也能开会

现象：没有作品时想先讨论第一本书写什么，系统却要求先创建作品。

修复：会议支持 `novel_id=0`，材料构建 allow_empty；结论 `next_book` 自动落成 planning 新书。

## 5. 数据层

### 5.1 空载荷建垃圾行

现象：无作品日更空转后 record_work 建出「未命名」publishing 书。

修复：空 payload 直接跳过，不落任何行；preflight 增加 `check_active_book`，无书直接 blocked。

### 5.2 迁移孤儿行

现象：章节去重删除主行后，子表留下孤儿引用。

修复：删除前清理 publish_logs/quality_reports/chapter_content/chapter_summaries/world_events/character_evolution 等全部子表；保留已发布行优先；SQL 用 EXISTS 写法兼容旧 SQLite。

### 5.3 多书串设定

现象：代理调用不带 novel_id，设定库以 0 查询形同虚设；日记/周会取最新书导致多书混乱。

修复：get_meta 输出 novel_id 并全链路透传；渲染脚本为全部代理节点注入 novel_id；日记、周会、会议显式绑定书 ID；validator 加断言。

### 5.4 幂等与并发

现象：同一次执行内多次 merge 输入导致成本重复记账；定时与手动同时触发双发。

修复：run_id 用执行 ID 幂等去重；原子创建运行锁（O_EXCL）+ PID 失效自动回收 + 陈旧阈值 2 小时（大于单次运行时长，防误删活锁）+ 所有退出路径释放 + 手动释放工具。

### 5.5 时区与时间字段

现象：前端用 `toISOString()`（UTC）与后端本地时间字符串比较，「今日任务」在凌晨 0–8 点全错。

修复：前端所有「今日/本周」统计用本地日期；后端时间统一本地时间字符串。

## 6. 前端面板

### 6.1 SSE 覆盖轮询

现象：执行记录页永远只显示最新 5 条（SSE 快照截断）；首页状态卡在「待命」。

修复：SSE 快照只补头部/合并，页面数据以完整轮询为准；SSE 断连自动重连 + 轮询兜底。

### 6.2 写死数字与假数据

现象：节点数写死且互相矛盾（60 vs 65）；伏笔台账等区块无数据源永远为空。

修复：节点数由后端动态返回；无数据源的死模块删除或接真实数据；审查时逐字段对照后端 API。

### 6.3 上限不一致

现象：前端弹窗 1–5 章、后端允许 10；表单校验 1–4、check_stock 允许 10。

修复：前后端上限统一（手动补更 5、每批 10），并加回归测试。

### 6.4 状态三态缺失

现象：加载中/空态/错误态没有合理 UI，或错误边界缺失导致整页白屏。

修复：首次加载骨架屏、页面级 ErrorBoundary、危险操作确认框、Toast 反馈。

### 6.5 实时通道单点

现象：SSE 断开后状态不再更新。

修复：SSE + 轮询双通道；执行状态与上次执行都能从轮询恢复。

## 7. 桌面壳

### 7.1 pywebview 不稳定

现象：无边框窗口 + 自绘标题栏在 WebView2 上 app-region 不生效、拖动高频调用、窗口偶发退出、白框闪烁。

修复：先退回系统边框 + DWM 深色标题栏，最终切换到 Electron（frameless + 自绘标题栏 + 托盘 + 通知 + 开机自启 + 自动更新）。

预防：需要「真正软件窗口」体验时直接选 Electron；pywebview 只作后备。

### 7.2 窗口启动白闪

现象：加载瞬间白屏。

修复：`index.html` 内联深色背景 + `color-scheme: dark`；`ready-to-show` 后再显示窗口。

### 7.3 API 进程生命周期

现象：面板退出后 web_api 进程残留，或重启后端口占用。

修复：Electron 启动时探测端口，未占用才拉起 `pythonw -m novel_pipeline.web_api`；窗口全关回收自起进程；单实例锁防止双开。

## 8. 工程与编码

### 8.1 路径硬编码

现象：换机器/换盘后所有 executeCommand 失效；python 不在 PATH。

修复：`PYTHON_EXE` / `PIPELINE_ROOT` 参数化；脚本自身 `Path(__file__).resolve()` 相对定位；启动器 vbs 相对化。

### 8.2 Windows 编码

现象：子进程中文输出抛 UnicodeDecodeError；PowerShell 传中文变 `?`。

修复：子进程读输出用 `errors="replace"`；跨进程中文数据走 UTF-8 文件或 Python urllib；终端脚本开头 `sys.stdout.reconfigure(encoding="utf-8")`。

### 8.3 双解释器

现象：executeCommand 的 command 已是解释器，commandArguments 首元素又带 `$env.PYTHON_EXE`，等于让 Python 解析 python.exe。

修复：参数化改造时全量检查；validator 增加「参数首元素不得是解释器」断言。

### 8.4 测试污染真实环境

现象：测试触发真实 n8n webhook、写真实数据库。

修复：测试统一临时库；webhook/外部调用 mock；run_tests.py 隔离运行时产物。

### 8.5 审查没有证据

现象：「再审查一遍」没有可复现记录，修了又漏。

修复：标准审查流程（`docs/engineering/review-process.md`）：证据优先、字段对照、动作对照、P0–P3 分级、报告落 `docs/reviews/`、附验证命令。
